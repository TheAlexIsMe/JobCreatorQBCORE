# JobCreatorQBCORE

An all-in-one dynamic job, shop, crafting, and rank-locked armory management resource designed for **QB-Core** framework servers. 

Created by **AlexVasquez**.

---

## Features
- 🏢 **Dynamic Multi-Location Support:** Establish multiple duty stations, boss menus, shared employee storefront stashes, secure vaults, and workstations anywhere on the map via configuration.
- 💼 **Society Fund Integration:** Shop purchases made by company managers automatically draw funds directly from the configured business account.
- 🔒 **Rank-Locked Armories:** Fully configurable equipment distribution for law enforcement (PD) and emergency services (EMS), restriction locked by grade rank.
- 🍕 **Advanced Crafting System:** Workers utilize raw inventory materials to cook/craft custom items with tracking requirements.
- 🎨 **Modern UI Dashboard:** Sleek glassmorphic HTML/CSS user interface.
- ⚙️ **Automatic Core Injection (`import.lua`):** Registers jobs, grades, and starting account funds directly into the server state without server reboots.
